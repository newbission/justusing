Applications, supporting documents and reports often have to be sent as a single PDF. Attaching each file separately is a hassle for the reader, and some upload systems take only one file. This guide shows how to merge PDF files into one, in the order you want.

## Steps

1. Open [Merge PDF](/en/pdf/merge/).
2. Click "Choose PDF files" and select all the files at once. You can also drag them onto the page.
3. Check the order in the list. Files at the top come first.
4. Click "Preview" to double-check the merged order.
5. Click "Merge PDF", then "Download" when it is done.

## Reordering files

- **Drag** a row to where you want it.
- Or use the **↑ ↓** buttons on the right of a row to move it one step. This works with the keyboard too.
- Remove a file you added by mistake with **×**.
- To add a missing file, click "Add files" or drag it onto the page again; it is added to the end of the list.

## Choosing pages

Click **▸** to the left of a file to show its pages.

- Drag pages or use **◀ ▶** to change their order within the file.
- **Exclude** pages you do not need, such as covers or blank pages. Excluded pages can be put back with "Restore".

The original files are not changed, so feel free to experiment. To mix or delete pages more freely, you can also merge first and then use [Organize PDF](/en/pdf/organize/).

## Password-protected PDFs

Enter the password for a protected file in the list, and it can be merged. The merged file has no password. To protect it again before sending, use [Protect PDF](/en/pdf/protect/). Passwords you enter are only used on this device and are never sent anywhere.

## Common problems

**The merged file is too big.** It is about the sum of the original files. Scans make it grow quickly; shrink the result with [Compress PDF](/en/pdf/compress/).

**Page sizes differ.** When you merge PDFs of different sizes, such as A4 and Letter, each page keeps its own size. When printing, use your printer's "Fit to paper" option.

**Will quality drop?** No. Pages are not redrawn; the content of the original PDFs is copied as it is, so text and photos are identical to the originals. Text search and copy still work.

**It is slow on my phone.** All files are processed in your device's memory, so merging files of several hundred MB on a phone with little memory can be slow or fail. Try a computer in that case.

## Why no upload?

Merging only joins files in order without changing their content, which modern browsers can do quickly on their own. With no need for a server, documents with personal information never leave your device.

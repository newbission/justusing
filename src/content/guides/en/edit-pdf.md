Sometimes you need to fill a name into a blank on a PDF form, fix a single amount on a quote, or mark the parts of a contract to check. This guide shows how to do it in your browser without paid PDF software.

## What you can do

| Tool      | What it does                         | When                                |
| --------- | ------------------------------------ | ----------------------------------- |
| Add text  | Write text anywhere on the page      | Filling in blanks, adding notes     |
| White out | Cover an area with a white rectangle | Covering a mistake to write over it |
| Highlight | Paint a translucent yellow box       | Marking parts to review             |

## Adding text

1. Open [Edit PDF](/en/pdf/edit/) and choose your PDF.
2. Choose **Add text** above, then click where the text should go.
3. Type in the "Text" box below. Line breaks work too.
4. Choose the font size and color (black, blue or red).
5. The first time, download a font from the list below. It is kept in this browser afterwards.

If the position is off, switch to **Select & move** and drag the text. With the keyboard, select it with Tab and move it with the arrow keys.

## Correcting text

Text that is already in the PDF cannot be edited directly. Instead:

1. Choose **White out** and drag over the wrong text to cover it.
2. Switch to **Add text**, click the covered spot and type the correct text.
3. Match the font size to the surrounding text.

This looks most natural on white pages; on colored or patterned backgrounds the white box will show.

## The limits of white out (please read)

White out **only places a white rectangle on top**. The original text stays in the file, so:

- copying or searching the PDF can reveal the covered text, and
- removing the rectangle in another program shows the original.

So **do not use it to remove personal information** such as ID or account numbers. If content must really be gone, use [Redact PDF](/en/pdf/redact/). It turns the redacted pages into painted images, so the text underneath is gone too.

## Signatures and stamps

- Handwritten signature: [Sign PDF](/en/pdf/sign/)
- Stamp or logo image: [Add Image to PDF](/en/pdf/add-image/)
- The same text on every page: [Add Watermark to PDF](/en/pdf/watermark/), [Add Header and Footer to PDF](/en/pdf/header-footer/)

## Is my file safe?

The PDF is edited only inside your browser and never sent anywhere. Downloading a font only fetches this site's public font file. Only the characters you use are embedded, so the file size barely changes.

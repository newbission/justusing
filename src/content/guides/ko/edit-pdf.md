받은 PDF 서류의 빈칸에 이름을 적어야 하거나, 견적서의 금액 하나를 고쳐야 하거나, 계약서에서 확인할 부분에 표시를 하고 싶을 때가 있습니다. 유료 PDF 편집 프로그램 없이 브라우저에서 할 수 있는 방법을 설명합니다.

## 할 수 있는 것

| 도구            | 하는 일                       | 이럴 때                    |
| --------------- | ----------------------------- | -------------------------- |
| 글자 넣기       | 쪽 위 원하는 자리에 글자 쓰기 | 빈칸 채우기, 메모 달기     |
| 흰색으로 가리기 | 사각형으로 흰색 덮기          | 틀린 글자를 덮고 새로 쓰기 |
| 형광펜          | 반투명 노란색 칠하기          | 확인할 부분 표시           |

## 글자 넣기

1. [PDF 편집](/pdf/edit/) 도구를 열고 PDF를 고릅니다.
2. 위의 도구에서 **글자 넣기**를 고르고, 쪽 위의 글자를 넣을 자리를 누릅니다.
3. 아래 "글자" 칸에 내용을 적습니다. 줄바꿈도 됩니다.
4. 글자 크기와 색(검정·파랑·빨강)을 고릅니다.
5. 처음이면 아래 글꼴 목록에서 글꼴을 받습니다. 한 번 받은 글꼴은 이 브라우저에 보관됩니다.

자리를 잘못 잡았으면 **고르기·옮기기**로 바꾸고 글자를 끌어 옮기면 됩니다. 키보드로는 Tab으로 고른 뒤 화살표 키로 옮깁니다.

## 틀린 글자 고치기

PDF 안에 원래 있던 글자는 직접 고칠 수 없습니다. 대신 이렇게 하면 고친 것처럼 만들 수 있습니다.

1. **흰색으로 가리기**를 고르고, 틀린 글자 위를 끌어 사각형으로 덮습니다.
2. **글자 넣기**로 바꾸고, 가린 자리를 눌러 바른 내용을 적습니다.
3. 원래 글자와 비슷한 크기가 되도록 글자 크기를 맞춥니다.

배경이 흰색인 문서에서 가장 자연스럽고, 배경에 색이나 무늬가 있으면 흰 사각형이 드러납니다.

## 흰색 가리기의 한계 (꼭 읽어 주세요)

흰색 가리기는 **위에 흰 사각형을 덮을 뿐**입니다. 아래 원래 글자는 파일에 그대로 남아 있어서,

- PDF에서 글자를 복사하거나 검색하면 가려진 내용이 드러날 수 있고,
- 다른 프로그램에서 사각형을 지우면 원래 내용이 보입니다.

그래서 주민등록번호·계좌번호 같은 **개인정보를 없애는 용도로는 쓰면 안 됩니다.** 내용을 정말 없애야 한다면 [PDF 가리기](/pdf/redact/)를 쓰세요. 가린 쪽을 칠한 그림으로 바꿔 아래 글자까지 없앱니다.

## 파일은 안전한가요?

PDF는 브라우저 안에서만 고치고 어디로도 전송되지 않습니다. 글꼴을 받을 때도 이 사이트의 공개 글꼴 파일만 받습니다. PDF에는 쓴 글자만 들어가 파일 크기도 거의 그대로입니다.

# 홈 상단 개편 독립 기획 리뷰

검토일: 2026-11-14. 기획 담당이 구현 담당과 분리해 실제 프로덕션 빌드(`http://localhost:8852/`, 영어 `/en/`)를 Chrome 157에서 관찰했다. 사용자 테스트나 실제 사용자 인수와 구별한다. 코드 변경은 하지 않았다.

- 기준: [레퍼런스 조사·선택·카피·수용 기준](./home-research.md), [A/B/C 와이어프레임](../home-reference-wireframes.html)의 선택 B.

- 최종 캡처/측정: `../evidence/home-reference-review/final/`. `{ko|en}-{1440|390|320}-{light|dark}-{first|story|photo}.webp`, `observations.json`. 대표 장면 전체는 `{ko|en}-scenes.webp`.
- 실제 관찰 조건: 1440×1000, 390×844, 320×844, 밝음/어두움, 한국어/영어, 감소 모션. 전체 페이지의 시각적 첫 화면·홈 소개 영역·사진 영역을 각각 확인한다. JS 없음·실제 파일 처리·CSP·성능·최초 노출 자동재생의 회귀 실행은 독립 검증 담당/root의 테스트 결과로 별도 다룬다.

## 중간 관찰과 반영

초기 8개 조합 관찰 중 root가 자료 안내의 공용 `guide-note` 스타일 충돌을 발견했고 구현 담당이 안내를 독립 클래스로 바꿨다. 초기 캡처는 상위 `home-reference-review/` 폴더에 중간 증거로 남겼다. 8852가 재빌드 중일 때 영어 390px 요청이 `ERR_HTTP_RESPONSE_CODE_FAILURE`로 한 번 실패했다. 서버 HTTP200 복귀 뒤 최종 앱 소스를 반영한 빌드에서 12개 조합을 다시 고정 확인했고 모두 정상 응답했다. 제품 오류와 빌드 중 서버 상태를 혼동하지 않는다.

## 화면과 읽기 흐름

한국어/영어 × 1440/390/320 × 밝음/어두움의 **12개 실제 렌더**에서 가로 넘침 0건. CTA 상단의 문서 좌표는 한국어 데스크톱 425px·390px 374px·320px 422px, 영어 데스크톱 515px·390px 374px·320px 446px였다. 모두 첫 화면 안에 시작점이 있다. 320px에서는 보조 CTA와 일부 대표 작업 링크가 다음 줄로 내려가지만 겹치거나 잘리지 않는다.

모바일은 제목/본문/무료범위/CTA/실제작업 링크/도식의 순서다. 도식이 첫 화면 전체 안에 들어오도록 무리하게 글씨를 줄이지 않았다. 320px에서 일부 단계 라벨은 두 줄로 정상 줄바꿈하며, 도식 단계 글씨는 14px이다. 큰 자료 안내 제목은 16px, 본문은 14px이며 내부 여백을 확보해 어두운 테마에서도 본문과 경계가 구별된다. 안내가 별도 거대한 장점 카드처럼 반복되지 않는다.

한국어 제목은 일상적인 효용과 차별점을 짧게 결합한다. 영어는 직역한 부정적 질문을 없애고 같은 기능/파일 위치/이용 조건을 전달한다. '어떤 데이터인가'는 공개 엔진·모델·언어 자료로 구체화되어 있다. 큰 자료에만 사전 용량·선택을 붙여 일반 도구 코드까지 매번 승인받는 것으로 오해시키지 않는다.

## 사진·장면 연결 확인

한영 실제 사진 비교는 원본 576.7KB→99.5KB 수치와 같은 화분 사진을 보여주며 '사진마다 다름' 캡션을 유지한다. 제목의 '100KB 아래'는 실제 결과와 맞는다. 이어지는 4개 장면에서 사진3장→PDF1개3쪽, 배경제거→투명PNG, PDF4쪽+2쪽→1개6쪽, 개인정보가리기→결과PDF의 의미가 읽힌다. 감소 모션 조건에서 정적 결과가 보이며 실제 결과를 장식으로 바꾸지 않았다. 최초1회 자동재생/이후수동은 별도 회귀검증의 대상이고, 이 리뷰는 그 실행 통과를 대신 주장하지 않는다.

## 사실성 검토와 한계

소스의 ToolFrame/FrameLayout/data/download 흐름과 공개 문구가 일치한다. 완벽한 보안, 모든 통신 없음, 전체 오프라인, 추가다운로드 없음, 가짜 인기/인증/후기를 추가하지 않았다. 홈 그림은 실행되는 도구나 파일 선택 UI처럼 보이지 않는 정적 설명이고 새 엔진을 홈에서 요구하지 않는다.

이 판정은 조사·카피·시각 흐름에 대한 독립 기획 리뷰다. 실제 파일 유출/접근성 전항목/성능 예산/전체 도구의 기능 회귀는 독립 검증 및 E2E 결과와 함께 최종 판단해야 한다. 실제 사용자에게 이해도를 측정하거나 인수를 받은 것으로 기록하지 않는다.

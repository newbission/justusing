# 소개와 전체 도구 목록 연결 — 2026-11-13

대표 기능 소개 뒤에 다른 도구 이용을 안내하고, 바로 아래에 기존 도구 모아보기를 배치해 달라는 사용자 요청을 반영했다. 기획 담당이 한영 문구와 실제 CSV·소리 추출 예시를 선정했고 구현 담당이 적용, 별도 검증 담당이 최종 HTML 순서/42개 고유 도구/접근성 연결/광고 간격을 확인했다. root는 추적 문서와 통합 검사·실제 CUA를 담당했다.

한국어는 “다른 도구도 살펴보세요.”와 “CSV 한글 깨짐을 고치거나, 동영상에서 소리만 꺼낼 수도 있어요. 아래에서 필요한 도구를 골라보세요.”다. 순서는 대표 장면→기존 광고→추가 도구 안내→도구 모아보기다. 새 CSS/JS/버튼/도구/전용 테스트는 추가하지 않았다. 새 문구의 '펴'가 다른 글꼴 조각을 추가 요청하지 않도록 기존 생성기로 글꼴을 다시 만들었다. 기존 광고 위치와48px 간격을 보존했다.

C-DIRECTORY-HANDOFF: 포맷·타입·프로덕션 빌드·diff와 기존 E2E28개(home8/font2/perf18) 통과. 근거 `../evidence/1794525990919996000-b410ad32.log`. CSP/local-only는 공통 테스트 fixture를 통해 검사했다. 이번 문구/배치 범위에서 모션 전체와 WebKit 전체를 재실행하지 않았고, 앞선74개 통과는 이전 변경의 기록으로 구별한다.

C-DIRECTORY-VISUAL: root가 실제 테일스케일 IAB에서 한영390px·한국어 데스크톱을 확인했다. 캡처는 `../evidence/home-directory-mobile-ko.png`, `home-directory-mobile-en.png`, `home-directory-desktop.png`. 문구가 잘리지 않고 안내와 도구 목록이 이어진다. 독립 검증에서 연결 CSS gzip9.811KB로 기존10KB 이내를 확인했고 정식 성능 E2E도 통과했다.

범위 내 필수 작업은 완료했다. 정식 공개 배포·커밋·PR·실제 사용자 폰 인수는 하지 않았다. 미리보기는 기존 Tailscale 중계를 사용한다. 전체 제품 gate의 과거 stale/인수 미기록과 이번 scoped 결과는 구분한다.

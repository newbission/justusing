# 대표 기능의 실제 전후 예시 확장

2026-11-13 · change · `codex/home-refresh` · 미커밋 변경. 사용자가 기존 사진 줄이기 예시 스타일을 마음에 들어 하며 다른 대표 기능도 선별해 보여 달라고 요청했다. 이전 홈 변경 위에 확장했다.

## 구현

기존 첫 화면의 사진 용량 맞추기는 유지하고, 아이콘 바로가기 목록을 실제 입력·결과 예시 6개로 바꿨다. 배경 제거, 정사각형 자르기, 사진을 PDF로, PDF 합치기, 가로 이어 붙이기, 개인정보 가리기다. `HomeShowcase.astro`가 한영 문구·문서 그림과 실제 도구 링크를 제공한다. PC2열·모바일1열, `#examples`로 바로 이동할 수 있다.

사진은 Patrick Pahlke·Erik Esly·Yana Hurska의 Unsplash License 소재를 직접 호스팅한다. 출처·재생성은 [사진 견본 문서](../../scripts/home/README.md). `make-showcase.mjs`로 실제 도구에서 결과를 만들고 투명 배경·857×857 자르기·1200×857 이어 붙이기·사진 PDF3쪽·합친 PDF6쪽을 확인했다. PDF 가리기는 가상의 전화·주민·계좌번호를 실제로 가린 뒤 결과에서 검색되지 않는 것을 확인했다. [생성 기록](../evidence/home-showcase-generation.log). 몽타주는 실제 결과를 축소·배치한 것이며, 사진 PDF의 앞2쪽·합친 PDF의 첫 쪽을 보여 준다는 점도 대체 글과 문서에 밝혔다.

## 검증

- 포맷·타입·프로덕션 빌드 통과: [기록](../evidence/1794498749194096000-6c1e1cfa.log). 타입·Svelte 오류/경고0, 기존 폐기 예정 API 등 힌트4개.
- **관련 E2E64개 통과**, 꺼진 광고 안내7개 제외(2.5분): [기록](../evidence/1794498792675891000-57128346.log). 새 예시6개를 한영에서 키보드로 열어 실제 frame 입력까지 확인하고, 이미지 지연 로딩·모바일 두 테마·홈 처리/다운로드·카테고리·언어·SEO·글꼴·성능·광고 격리·사이트맵 전체 CSP·WebKit smoke3개를 포함했다.
- 실제 브라우저에서 테일스케일 주소의 최신 빌드를 확인했다. PC의 한국어·영어와 밝은/어두운 화면, 모바일의 영어 라이트·한국어 다크를 관찰했다. [전체 예시 캡처](../evidence/home-showcase-gallery.webp), [영어 모바일](../evidence/home-showcase-mobile-en.png), [한국어 모바일 다크](../evidence/home-showcase-mobile-ko-dark.png).
- [성능 실측](../evidence/home-showcase-performance.log): 홈 HTML gzip19.1KB / CSS8.0KB / 글꼴102.1KB / 그림143.5KB / 요청15회. 별도 JS 파일 없음. 원본 대신720×440 WebP6개를 고정 크기·지연 로딩으로 추가했다. 홈 그림 예산만64→170KB, 요청12→18회로 조정하고 JS·CSS·글꼴 상한을 유지했다. PDF 합치기 등 기존 페이지도 예산을 통과했다.
- 최초 실행은 공개 이미지 `photos.webp`가 개인정보 검사 기준인 `photos.pdf`의 파일명과 겹쳐 실패했다. 사용자 파일 전송은 없었고 공개 자산을 `album.webp`로 바꿨다. 개인정보 검사는 수정하지 않았으며 실패 기록은 보존했다.
- 문서 인덱스 문제 없음, `git diff --check` 통과. C-SHOWCASE·C-SHOWCASE-QUALITY의 현재 범위는 verified다. 예전 작업 인수·증거까지 포함하는 전체 제품 게이트와 구별한다.

## 전달과 한계

기존 테일스케일 HTTP4323 미리보기에서 응답200과 예시6개 반영을 확인했다. 실제 사용자 폰의 접속·파일 처리를 대신 관찰한 것은 아니다. 정식 공개 사이트의 배포, 커밋·PR은 하지 않았다. 기존 전체42개 도구와 파일 처리·격리·광고 설정은 유지했다. 다음 선택 작업은 시각 피드백 반영 또는 저장소 절차에 따른 커밋·리뷰·배포다.

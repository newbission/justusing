# 대표 장면 첫 노출 자동재생 — 2026-11-13

사용자의 요청대로 대표4개 장면을 화면에 처음 보일 때1회 자동재생하고, 이후에는 버튼으로 재생하도록 바꿨다. 페이지 렌더 직후 보이지 않는 장면을 먼저 재생하지 않는다. 기획 담당이 노출/우선순위 정책을 정하고 구현 담당이 적용했으며, 별도 검증 담당이 기존 motion-review 테스트를 요구 변경에 맞게 갱신했다. 최종 테스트 실행·해석과 실제 브라우저 검증은 root가 수행했다.

## 동작

`.demo-stage`가50% 이상 보이는 첫 순간에 단일 IntersectionObserver로 감지한다. 다른 장면이 재생 중이면 현재 보이는 미재생 장면을 대기시킨다. 자동재생은 수동 재생/정지를 가로채지 않으며, 실제 시작 또는 수동 조작 시 자동 기회를 소비하고 관측을 해제한다. 첫 단회가 끝난 뒤 다시 스크롤해도 자동으로 반복하지 않는다. 수동 재생·정지·재개는 유지한다.

숨겨진 탭/감소 모션에서는 시작하지 않는다. 탭이 보이면 노출 조건을 다시 확인한다. 상태는 페이지 안에만 두므로 새로고침/재방문은 새 첫 노출이다. JS가 없으면 기존 정적 결과를 제공한다. 새 CSS/폰트/의존성/스토리지/네트워크 요청/도구 처리는 추가하지 않았고 성능 상한도 유지했다. 제품 문구와 소개→도구 목록 구성은 유지했다.

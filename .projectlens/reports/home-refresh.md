# 홈 화면 개편 결과

2026-11-13 · change · `codex/home-refresh` · 시작점 `origin/dev` c6071ea7 · 미커밋 변경.

## 결과

기능·안전성 설명을 반복하던 홈을 짧은 소개, 실제 사진 처리 결과, 대표 도구 6개, 전체 도구 탐색으로 바꿨다. 한영 화면 모두 반영했다. 홈 카드만 `summary`로 줄이고 모든 42개 도구 링크·카테고리별 묶음을 유지했다. 새 런타임 JS·대시보드·사용자 데이터 수집·격리 정책 변경은 없다. 시각 디자인의 사용자 인수는 아직 받지 않았다.

사진은 Patrick Pahlke의 Unsplash License 소재를 직접 호스팅하며, 우리 용량 맞추기 도구로 원본 576,710바이트를 99,486바이트로 만든 실제 결과다. 화면은 축소 WebP이고 수치는 실제 JPG를 기준으로 표시한다. 출처와 재생성은 [사진 견본 문서](../../scripts/home/README.md), 요청·기준은 [홈 명세](../home-refresh.md).

## 검증

- `npm run format:check`, `npm run check`, `npm run build` 통과. 타입·Svelte 오류/경고 0개, 기존 deprecated API 등의 힌트 4개. [통합 실행 기록](../evidence/1794496824194953000-7d3e74c3.log)
- 관련 Chromium 검사 55개 + WebKit smoke 3개 = **58개 통과**. 꺼진 광고 차단 안내 7개는 설정상 제외. 홈의 실제 처리·다운로드·키보드 진입, 한영 탐색·모바일 두 테마·사진, 기존 카테고리·언어·SEO·글꼴·성능·광고 격리, 사이트맵 전체 페이지의 CSP 검사를 포함한다. [E2E 기록](../evidence/1794496863236084000-9dc2974e.log)
- 실제 브라우저에서 데스크톱·390×844 모바일, 한국어·영어와 두 테마를 관찰했다. 최종 빌드의 [데스크톱](../evidence/home-desktop-light.png)·[모바일](../evidence/home-mobile-light.png) 라이트 캡처를 확인했다.
- [성능 실측](../evidence/home-performance.log): 홈 HTML gzip18.0KB / CSS7.9KB / 글꼴101.4KB / 이미지62.9KB / 요청9회. 영어는 글꼴36.1KB, 요청8회. 별도 JS 파일 수신 없음. 사진 2장에 필요한 홈 이미지·요청 예산만 조정했다. 나머지 성능 예산은 모두 유지했다.
- 글꼴 분할의 회귀를 수정해 PDF 합치기 바깥 글꼴 수신량은 첫 실행156.2KB→127.4KB(상한155KB), frame 첫 화면101.4KB(상한117KB)다.
- `git diff --check` 통과. ProjectLens 문서 인덱스의 누락·관계 문제 없음. 현재 범위 C-HOME와 C-HOME-QUALITY는 verified. 기존 전체 제품 게이트는 이전 작업의 인수·증거 상태를 포함하므로 이번 결과와 구별한다.

## 발견하고 보완한 점

이전 제목과 홈 애니메이션을 기대하던 테스트를 새 구성에 맞췄다. 대표 링크가 생겨 영어 테스트의 부분 문자열 검색이 두 링크를 고르는 문제는 대표 도구 영역 안의 정확한 이름으로 선택하도록 수정했다. 홈 문구 축소로 글꼴이 두 rest 조각에 흩어진 성능 회귀는 목록 페이지의 공통 글자도 core에 유지해 해결했다. 초기 실패·중단 실행은 증거로 보존했다.

## 범위와 다음 단계

커밋·PR·배포는 하지 않았다. 로컬 미리보기는 `http://127.0.0.1:4322/`이며 Wrangler가 배포와 같은 CSP·격리로 제공한다. 사용자에게 시각 결과를 보여주는 단계다. 이번에 전체 도구 E2E 전부, 실제 아이폰·네이티브 Safari, 실광고 슬롯은 검사하지 않았다. 사용자 파일 처리 코드는 변경하지 않았다.

관련 파일: `src/pages/index.astro`, `src/i18n/ui.ts`, `src/site.config.ts`, 도구 카드 3개 부품, `src/assets/home/`, `scripts/home/`, 글꼴 생성기와 생성 파일, 홈·언어·CSP·성능 E2E, 사이트 구조 문서와 ProjectLens 기록.

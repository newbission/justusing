# 로컬 처리 우선 홈 — 2026-11-13

사용자 요청대로 파일이 기기를 떠나지 않는 차별점을 첫 화면으로 올리고, 기존 사진 용량 비교와 대표4개 기능 소개는 두 번째 흐름으로 보존했다. 첫 H1은 **파일은 내 기기에. 처리는 브라우저에서.**이며, 파일 내용·이름 비전송 본문과 기기/브라우저 경계 안의 선택→처리→저장 도식을 배치했다.

## 결과와 근거

기획 담당이 `../home-local-first-plan.md`에 한영 문구·정보구조·실제 구조 근거·수용 기준을 작성하고 구현 담당이 index/UI/tagline/정적 HomeLocalFlow를 적용했다. 별도 검증 담당은 사실성·최종HTML순서/42개도구/광고간격·캡처/모바일WebKit을 독립 확인했다. root는 추적 문서와 최종 통합·실제 CUA 확인을 맡았다. 기획 독립 리뷰는 `home-local-first-planning-review.md`.

첫 주 CTA는 기존42개 도구 목록으로, 보조 CTA는 같은 언어의 안전 설명으로 간다. 기존 사진 압축 CTA/실제576.7→99.5KB와4개 단회 자동재생 장면/추가도구 안내를 유지했다. 사진은 lazy로 바꾸고 중복 하단 trust는 제거했다. 새 처리/네트워크/의존성/런타임JS/스토리지는 추가하지 않았다. 상한은 올리지 않았고 독립 CSS 합산은9.786KB(기존10KB이내)다. 최종 성능 E2E도 통과했다.

약속은 실제 sandbox/CSP·파일 로컬처리·파일내용과이름 비전송에 한정한다. 100%안전/완벽보안/사이트외부통신0/인터넷불필요는 주장하지 않는다. 프로그램·모델 리소스 및 바깥 광고/방문통계의 네트워크 요청이 존재한다는 기존 설명과 모순되지 않는다. 이번에 해당 보안경계 자체를 변경하지 않았다.

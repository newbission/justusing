## 실제 구조·이해도 판단

첫 제목과 구체 작업 예,42개 무료 도구·앱 설치/가입 없음, 전체 도구 CTA·대표4개 바로가기가 먼저 읽힌다. 이전 부정 질문3개와 반복 무료 소개가 없어지고 각 후속 영역이 처리 원리, 격리 이유, 자료 수신 주의를 추가한다. 데스크톱에서는 설명과 도식이 함께 보이고, 모바일에서도 시작 버튼이 첫 화면에 남는다.

도식은 사이트에서 공개 처리 프로그램·자료를 받는 아래 방향과, 기기 안 도구 영역의 파일 선택→처리→결과 저장을 구분한다. 바깥 광고·통계는 도구 영역 밖에 표시된다. 실제 ToolFrame/FrameLayout/worker/data-store/download 구조와 일치하며 sandbox·CSP를 넓히거나 광고/통계를 안쪽으로 옮기는 변경은 없다.

한영 문구는 공개 엔진·모델·언어 자료를 받는다는 사실, 큰 자료의 용량과 받기 선택, 모바일 데이터 사용 가능, 보관본 삭제 뒤 재수신 가능을 설명한다. 일반 처리 코드까지 모두 받기 동의를 요구한다거나 추가 다운로드/외부 통신/오프라인 제한이 없다고 과장하지 않는다. 앱 설치와 브라우저 자료 수신도 별도로 설명한다. 새 의존성·무거운 홈 처리·가짜 후기/이용자 수/인증을 추가하지 않았다.

이번 재검토의 필수 수정 요청은 없다. 앞선 WebKit18개, 전체 한영·세 폭·두 테마·normal/reduced/noJS36조합, 전체 접근성12조합은 실행 주체와 시점을 기존 보고서에 보존하며, 불필요하게 대량 반복하지 않았다. 독립 담당이 발견했던 대비4.00:1 문제는 코드·영구 회귀·최종 화면 세 근거로 해소를 확인했다.

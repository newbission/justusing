# 홈 주요 작업 장면 개편 — 2026-11-13

사용자가 지적한 이미지→PDF의 결과 의미 오류를 고치고, 핵심 작업4개의 입력→동작→결과를 큰 장면으로 재구성했다. 기획·구현·독립 검증을 별도 에이전트에 맡겼으며 root는 문서/통합검증/실제 브라우저 확인을 맡았다. 사용자의 실제 기기 인수나 공개 배포를 대신하는 보고서는 아니다.

## 역할과 범위

- 기획 `/root/planning`: 기존 화면 관찰, 대표 기능 선정·정보구조·한영 문구·wireframe·수용 기준을 `../home-motion-plan.md`에 작성. 실제 캡처를 따로 열어 문구/구성/결과 의미를 검토한 기록은 `home-motion-planning-review.md`.
- 구현 `/root/implementation`: `HomeShowcase.astro`, 홈 CSS와 문구, 실제 출력 sprite/생성기와 E2E. 사용자가 좋아한 사진 압축 hero와42개 도구 탐색 유지.
- 독립 검증 `/root/verification`: 실제 PDF3쪽/합친6쪽/가린 정보 검색불가 확인, 구현과 별도 `home-motion-review.spec.ts` 작성, Chromium10개와 모바일 크기 WebKit10개 실행, 실제 캡처 독립 검토.
- root: 저장소 상태·문서, 발견사항 통합, 최종 프로덕션 빌드와 회귀, CUA 실제 화면/테일스케일 확인. 구현 담당의 소스와 기획 담당의 제품 문구를 대신 작성하지 않았다.

계정/관리대시보드·실제 도구 처리 기능·광고/통계·격리/CSP 정책은 이번 변경 대상이 아니다. 커밋·PR·정식 공개 배포는 하지 않았다.

## 최종 화면과 동작

이미지→PDF, 배경 제거, PDF 합치기, PDF 가리기를 넓은4개 구간으로 보여 준다. 이미지→PDF의 사진3장은 한 문서 뷰어 안의3쪽으로 묶인다. PDF 합치기는 보고서4쪽+부록2쪽→한 파일6쪽, 배경제거는 남길 대상 선택→실제 투명PNG, 가리기는 가상 정보의 같은 부분을 확대한 실제 삭제 결과다. 사진/문서 결과는 기존 도구에서 생성한 파일을 축소한 sprite로 직접 호스팅한다.

기본 상태는 완결된 정적 결과다. 사용자가 누르면4.8초 한 번 재생하고 정지·재개·다시 재생할 수 있다. 다른 장면을 재생하면 기존 장면을 정지한다. 감소 모션과 JS불가에서도 입력/결과 의미를 유지하며 재생 제어는 숨긴다. 재생 버튼과 실제 도구 링크를 구별한다. 새 처리모델·워커·애니메이션 의존성·자동 다운로드를 홈에 추가하지 않았다. 작은 홈 전용 상태 코드는 기존 페이지 인라인 번들에 포함된다.

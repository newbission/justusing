# pdf-header-footer — 검증·오류·수정 히스토리

쓴 날 2026-10-16 · 고친 날 2026-10-16

## 요약

- 2026-10-15: 워터마크 워커를 "글자 넣기 워커"(`text-pdf`)로 넓혀 같은 워커에서 넣는다 (fontkit을 한 번만 싣게).
  자리 계산(`header-footer-layout.ts`)을 미리보기와 워커가 같이 쓴다
- 긴 머리말이 가운데·오른쪽 정렬에서 쪽 밖으로 잘렸다 → 쓸 폭에 맞게 글자 크기를 줄인다 (`fitSize`)
- 숫자 자리표시가 없어도 0~9를 검사해 숫자 없는 글꼴을 못 썼다 → 자리표시를 채운 실제 글자만 검사한다
- 아주 좁게 잘린 쪽에서 쓸 폭이 0 이하가 되어 글자 크기가 0이 되었다 → 여백을 변 길이의 10%까지만 쓴다
- 낮은 쪽에서 머리말·꼬리말이 겹쳤고, `/UserUnit`이 1이 아닌 PDF는 크기·여백이 그 배수로 커졌다
  → 높이의 30% 이하로 줄이고, 자리는 pt로 계산해 그릴 때 쪽 단위로 나눈다
- 글자를 칠 때마다 미리보기 글꼴(`FontFace`)을 다시 만들어 입력이 버벅였다 → 글꼴 바이트를 따로 derived로 둔다
- 자정을 넘겨 열어 둔 탭에서 전날 날짜가 들어갔다 → 실행할 때·탭으로 돌아올 때 다시 계산하고 날짜를 결과 서명에 넣는다
- 한 쪽 문서에서 표지를 빼면 넣을 글자가 없어 'font required'로 실패했다 → 글꼴 없이 그대로 저장한다
- 미리보기 색을 토큰으로 하라는 리뷰는 고치지 않았다: PDF에 넣을 색이라 PDF RGB 값에서 만들어야 결과와 같다
- 2026-10-15: 배포 (PR #50은 2026-10-16 dev 병합)

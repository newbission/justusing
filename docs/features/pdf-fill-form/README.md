## 1. 어떤 기능인지

- 입력 칸(양식 필드, AcroForm)이 있는 PDF의 칸을 **쪽 위 그 자리에서** 채운다 (신청서·계약서 등)
- 입력: PDF 하나. 한글처럼 기본 글꼴에 없는 글자를 적으면 글꼴도 고른다
- 출력: `<원래 이름>_작성.pdf` (영어 화면 `_filled.pdf`)
- 다루는 칸

| PDF 칸                                   | 화면                                                                             | 저장하는 값                                     |
| ---------------------------------------- | -------------------------------------------------------------------------------- | ----------------------------------------------- |
| 글자 칸 (`Tx`)                           | `input`/`textarea`(여러 줄), 최대 글자 수 지킴                                   | 적은 글자                                       |
| 암호 칸 (`Tx` + `/Ff` Password `0x2000`) | `type="password"`                                                                | 값은 적은 그대로, **모양에는 같은 길이의 `*`**  |
| 체크 상자 (`Btn`)                        | checkbox. 같은 이름에 켜는 값이 다르면 이름에 값을 붙임                          | 켠 상자의 값 (`/V`), 그 상자만 `/AS` 켬         |
| 라디오 (`Btn`)                           | radio (`이름: 값`). `NoToggleToOff`(`0x4000`)가 없으면 다시 눌러 끔              | 고른 단추 값                                    |
| 선택 상자 (`Ch` combo)                   | select. `/Ff` Edit(`0x40000`)면 datalist 붙은 입력 칸(선택지에 없는 글자도 적음) | **내보내는 값** (예: 화면 "대한민국" → 값 `KR`) |
| 목록 (`Ch` list)                         | select (`multiple` 또는 하나만)                                                  | 내보내는 값들, `/I`(고른 번호)도 맞춤           |

- "칸을 글자로 굳히기"(flatten): 칸을 없애고 적은 내용을 쪽 위 글자로 바꾼다. 굳히기만 하고 저장할 수도 있다
- **하지 않는 것·한계** (화면·FAQ와 같게)
  - 칸이 없는 PDF는 "채울 수 있는 입력 칸이 없습니다" → "PDF 편집"을 안내
  - 서명 칸(전자서명 필드)은 인증서가 필요해 채우지 않는다 (손글씨 서명은 "PDF 서명 넣기")
  - 숨은 칸, 누름 단추는 보여 주지 않는다. 읽기 전용 칸은 보이지만 고칠 수 없다
  - 일부 프로그램은 칸을 자기 글꼴로 다시 그려 달라 보일 수 있다 → 굳히면 어디서나 같다
  - 굳히면 칸으로 되돌릴 수 없다 (원본 보관 안내)
  - XFA 양식은 남겨 두면 다른 프로그램이 넣은 값 대신 XFA를 보여 줘서 **지운다**
  - 결과 PDF에는 원본 암호가 남지 않는다

## 2. 어떻게 만드는지

### 파일

| 파일                                  | 역할                                                                               |
| ------------------------------------- | ---------------------------------------------------------------------------------- |
| `src/tools/pdf/fill-form/meta.ts`     | 이름·설명·아이콘, 묶음 `edit`, 관련 도구 `pdf/sign`·`pdf/edit`                     |
| `src/tools/pdf/fill-form/content.ts`  | 사용법·FAQ (한·영)                                                                 |
| `src/tools/pdf/fill-form/messages.ts` | 화면 문구                                                                          |
| `src/tools/pdf/fill-form/App.svelte`  | 칸 읽기(`readFields`), 쪽 위 입력 칸 겹치기, 바뀐 값 모으기, 글꼴 필요 판단, 저장  |
| `src/lib/pdf/fill-form.ts`            | `fillForm()`, `FieldValue`(text / check / choice), `FormValues`, `FillFormOptions` |
| `src/lib/pdf/text-pdf.worker.ts`      | `formText()`(글꼴 검사할 글자), `fillFields()`(값 넣기·모양 만들기·굳히기)         |
| `src/lib/pdf/PageSheet.svelte`        | `hideForms` — 쪽을 그릴 때 원래 칸 모양을 빼서 겹친 입력 칸과 겹쳐 보이지 않게     |
| `src/lib/fonts/FontPicker.svelte`     | 글꼴이 필요할 때만 보인다                                                          |

### 처리 흐름

1. PDF를 열면 `readFields()`가 쪽마다 pdf.js `getAnnotations()`에서 `Widget`을 읽는다
   - `Tx`·`Btn`·`Ch`만, 이름 없는 것·숨은 것·누름 단추는 뺀다
   - 칸 자리(`rect`)를 viewport 좌표로 바꿔 **쪽 비율**로 둔다. `fieldFlags`로 Edit·Password·NoToggleToOff를 읽는다
   - 이름마다 지금 값을 `initial`에 둔다. 칸이 있는 첫 쪽부터 보여 준다
2. 사용자가 칸을 채우면 값은 `SvelteMap`(`values`)에 둔다. `initial`과 다른 것만 `changed`
3. 글꼴이 필요한지(`needsFont`): 바뀐 칸이 **모양으로 그릴 글자**(암호 칸 제외, 선택 칸은 보이는 글자, 목록은 선택지 전체)에
   Latin-1 밖 글자가 있거나, 저장해 보니 기본 글꼴에 없는 글자가 있었을 때(`fontRequired`)
4. "양식 저장" → `canUse('pdf/fill-form')` → `fillForm({ values: structuredClone(changed), font?, flatten })`
5. 워커 (`text-pdf.worker.ts`)
   1. `formText()`로 모양에 그릴 글자를 모아 글꼴에 없는 글자를 검사한다: 바꿀 칸의 새 글자 + 바꾸지 않았어도
      `needsAppearancesUpdate()`인 칸(모양이 없거나 낡은 칸)의 지금 글자. 암호 칸은 `*`로 센다
   2. `fillFields()`
      - XFA가 있으면 지운다
      - 모양을 다시 만들 **바꾸지 않은 선택 상자·목록**(읽기 전용 포함)도 보이는 글자로 골라 두고 나중에 값을 되돌린다
      - 바꾼 칸에 값 넣기 (읽기 전용 칸은 건너뜀). 체크 상자는 `/V`와 위젯별 `/AS`를 직접 적는다
      - 암호 칸은 잠시 `*`로 바꿔 모양을 그린 뒤 `/V`를 원래 글자로 되돌린다
      - `updateFieldAppearances(글꼴 또는 Helvetica)`로 모양을 만든다. 글꼴이 없는데 Helvetica에 없는 글자가 있으면
        그 글자를 돌려준다 → 화면은 `fontRequired = true`로 글꼴을 고르게 한다
      - 선택 칸 `/V`(목록은 `/I`도)를 **내보내는 값**으로 적는다
      - 굳히기면 `form.flatten()`
6. 결과 `signature` = 바뀐 값 + 굳히기 + (필요하면) 글꼴 id

### 결정과 이유

- **목록이 아니라 쪽 위에서 채운다**: 서식 목록보다 종이 서류처럼 그 자리에서 적는 편이 알아보기 쉽다 (`a9534ef`)
- **pdf-lib는 한글을 오류 없이 빼 버린다**: 칸의 기본 글꼴(Helvetica)에 한글이 없다. 그래서 글자 넣기 워커에서 고른 글꼴로
  모양을 만들고, 글꼴 없이 빠질 글자가 있으면 미리 알린다 (`dc2e58a`)
- **모양은 보이는 글자, 값은 내보내는 값**: pdf-lib `select()`는 보이는 글자를 값으로 저장해, 내보내는 값(`KR`)을 읽는
  제출처 처리가 틀어졌다. 모양을 만든 뒤 `/V`를 직접 고쳐 쓴다
- **체크 상자 값 = 켠 상자의 값**: 같은 이름에 켜는 값이 다른 상자(세금 양식 등)를 켬/끔 하나로 묶으면 모두 함께 켜졌다.
  pdf-lib `setValue`가 켜는 값이 하나인 상자만 받아 직접 적는다
- **암호 칸은 모양에 `*`**: 화면만 가리고 저장 모양에 평문을 그리면 굳힐 때 PIN·비밀번호가 쪽 내용으로 남는다
- **칸 이름은 `Map`과 `Object.hasOwn`**: 이름이 `__proto__`·`constructor`인 칸이 있으면 일반 객체에서 이미 있는 것으로
  보이거나 값을 넣지 못했다. 화면은 `SvelteMap`, 워커로는 `structuredClone`으로 넘기고 워커는 `Object.hasOwn`으로 본다
- 원래 칸 모양은 `PageSheet`의 `hideForms`로 빼고 그린다 (예전 값이 겹쳐 보이지 않게, `db44c7a`)

### 주의할 점

- 화면의 `drawnText`(글꼴 필요 판단)와 워커의 `formText`(글꼴 검사)는 같은 규칙이어야 한다
  (암호 칸 빼기, 선택 칸은 보이는 글자, 목록은 선택지 전체)
- 선택 칸을 고칠 때 "보이는 글자로 모양 → 내보내는 값으로 되돌리기" 순서를 지킨다. 바꾸지 않은 칸·읽기 전용 칸도 해당된다
- 체크 상자·라디오는 pdf-lib 고수준 API(`check`, `setValue`)로 바꾸면 같은 이름 상자 처리가 다시 깨진다
- 칸 이름으로 일반 객체 키를 쓰지 않는다 (`in`, `obj[name]` 금지). `changed`는 `Object.fromEntries`로 만든다
- 입력 칸 글자 크기는 칸 높이에 맞춰 8~16px (`fontSize()`), 암호 칸에도 같은 칸 모양 CSS를 건다

## 4. 검증

### 자동 테스트

`tests/e2e/pdf-fill-form.spec.ts` (테스트 안에서 pdf-lib로 양식 PDF를 만들고, 결과를 pdf-lib·pdf.js로 다시 읽는다)

- `글자·체크·라디오·선택 칸을 채우고, 한글은 고른 글꼴로 넣는다` — 한글을 적으면 글꼴 안내, "4칸을 고쳤습니다.",
  결과 이름 `application_작성.pdf`, 칸 값 확인, `expectLocalOnly`
- `굳히면 칸이 사라지고 적은 글자가 쪽에 남는다`
- `입력 칸이 없는 PDF는 편집 도구를 안내한다`
- `한글을 굳히면 고른 글꼴로 그린 글자가 쪽에 남는다`
- `선택 상자는 보이는 글자가 아니라 내보내는 값을 저장한다` — "대한민국"을 고르면 값 `KR`
- `같은 이름의 체크 상자는 누른 상자만 켠다`
- `직접 적을 수 있는 선택 상자에는 선택지에 없는 글자도 적는다`
- `암호 칸은 적은 글자를 가려 보여 준다`
- `굳힐 때 모양을 다시 만들어야 하는 기존 한글 값이 있으면 글꼴을 고르게 한다`
- `암호 칸을 굳히면 적은 글자 대신 가린 글자가 쪽에 남는다`
- `바꾸지 않은 선택 상자의 모양을 다시 만들 때도 보이는 글자로 그린다`
- `읽기 전용 선택 상자와 목록도 모양을 다시 만들 때 보이는 글자로 그린다`
- `한글 암호는 글꼴 없이 가려 저장하고, 암호 칸은 PDF 칸 크기에 맞춘다`
- `끌 수 있는 라디오는 고른 단추를 다시 눌러 고르지 않은 상태로 돌린다`
- `__proto__·constructor 같은 이름의 칸도 지금 값을 보여 주고 고쳐 저장한다`

리뷰 지적으로 더한 E2E는 "예전 코드에서는 실패"하는 것을 확인했다고 리뷰 답글에 적혀 있다.

# pdf-watermark — 검증·오류·수정 히스토리

## 요약

- 2026-10-15: 글꼴 기반(한글 글꼴 8종 직접 호스팅, 받기 전 동의·Cache API 보관)과 함께 만든 첫 글꼴 도구다
- fontkit이 커서 글자 넣기 워커를 고치기 워커와 따로 두었다 (뒤에 머리말·꼬리말·편집·양식 채우기도 여기에 붙음).
  쓴 글자만 넣어(subset) 결과가 거의 커지지 않고, 글꼴에 없는 글자는 빈 네모로 찍히기 전에 알린다
- 자리 계산(`watermark-layout.ts`)을 화면 미리보기와 워커가 같이 써서 미리보기와 결과가 같다
- 미리보기 오류: 글꼴을 바꾼 뒤 이전 글꼴이 늦게 읽히거나, 쪽을 빠르게 넘기면 이전 쪽 크기로 그려졌다
  → `$effect`마다 `current` 플래그로 늦게 온 결과를 버린다
- 반복 배치 300개 제한에 닿으면 쪽 위쪽만 덮였다 → 간격을 고르게 넓혀 다시 놓는다. 아주 긴 쪽에서는 후보를 다 만들다
  화면이 멈출 수 있었다 → 넓이로 개수를 먼저 어림한다 (10×10000pt 쪽 6ms)
- 리뷰에서 글꼴 기반 지적이 많았다: 검증 안 된 응답을 보관하지 않기(기대 SHA-256을 함께 보냄), 마지막으로 고른 글꼴만
  반영, 올린 글꼴마다 다른 id, 예약 글꼴 이름(Pretendard·Nanum)을 우리 이름으로 바꾸기(P1)
- 배운 점: 비동기로 읽는 글꼴·쪽 크기는 "늦게 온 이전 결과"를 늘 버려야 미리보기와 결과가 같다
- 2026-10-15: 배포 (PR #47은 2026-10-16 dev 병합)

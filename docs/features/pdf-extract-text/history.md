## 요약

- 2026-10-14 pdf.js `getTextContent()`로 쪽마다 글자를 읽어 화면에 보여 주고 TXT로 받게 했다. 줄 끝(`hasEOL`)에서 줄을 바꾸고, 쪽마다 `--- 1쪽 ---` 구분 줄을 넣는다.
- 2026-10-14 TXT는 CRLF와 UTF-8 BOM으로 저장한다. 메모장에서도 줄이 바뀌고 한글이 깨지지 않는다 (OCR의 TXT도 같은 방식).
- 2026-10-15 (Codex P1) 추출을 워커로 옮기라는 지적은 일부만 반영했다. 읽기는 이미 pdf.js 워커가 하고 화면은 쪽마다 기다리며 그 쪽만 잇는다.
  다 읽은 뒤 전체를 다시 훑어 세던 부분만 쪽마다 세도록 바꿨다. 남은 잇기·인코딩은 수백 쪽에서도 수 ms라 두었다.
- 한글 PDF는 pdf.js가 CMap 파일을 받아야 읽힌다. E2E가 `korean.pdf`로 확인한다.
- 2026-10-16: FAQ가 OCR을 "아직 없다"고 하던 것을 OCR 도구 안내로 고쳤다 (문서를 쓰다 발견).

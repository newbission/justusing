## 1. 어떤 기능인지

- 해상도와 화질(또는 목표 용량)을 골라 동영상을 다시 저장해 용량을 줄인다
- 입력: 동영상 하나 (MP4·MOV·WebM·MKV). 화면 트랙이 있고 이 브라우저가 풀 수 있어야 한다
- 출력: `<이름>_줄임.mp4` (H.264 + 소리). 브라우저가 H.264로 저장하지 못하면 `.webm`(VP9 + Opus)
- 해상도: 원래 크기와, 원본 짧은 변보다 작은 1080p·720p·480p. 그 크기를 저장하지 못하면 고를 수 없게 표시. 기본은 원본이 720p보다 크면 720p
- 화질: 높음·보통·낮음 / 목표 용량(MB). 막대에 예상 용량
- 소리: MP4는 AAC·MP3를 그대로 옮기고 그 밖은 AAC로(못 하면 Opus·FLAC는 옮김), WebM은 Opus·Vorbis를 옮기고 그 밖은 Opus로. 못 하면 빠진다고 미리 알린다

하지 않는 것·한계

- 결과가 원본보다 작지 않으면 받기를 내주지 않는다 (이미 작게 저장된 영상)
- 목표 용량은 비트레이트로 맞추므로 조금 넘거나 모자랄 수 있다 (FAQ·가이드에 밝힘)
- 장면 수(fps)·소리 품질은 바꾸지 않는다. HDR은 다루지 않는다(브라우저가 주는 대로)
- 동영상 길이만큼(또는 그 이상) 걸린다. 휴대폰은 느리다

## 2. 어떻게 만드는지

### 파일

| 파일                                       | 역할                                                                     |
| ------------------------------------------ | ------------------------------------------------------------------------ |
| `src/tools/video/compress/App.svelte`      | 미리보기, 해상도(라디오), 화질·목표 용량, 저장 형식·소리 안내, 예상 용량 |
| `src/tools/video/compress/messages.ts`     | 문구 (한·영)                                                             |
| `src/lib/video/plan.ts`의 `compressPlan`   | 크기·동영상 비트레이트·소리 방법·예상 용량 (화면과 처리 코드가 같이 씀)  |
| `src/lib/video/engine.ts`의 `planCompress` | 코덱 고르기(avc → vp9), `forceTranscode`, `fit: 'fill'`(짝수 크기)       |

### 결정과 이유

- H.264 MP4 우선: 휴대폰·메신저·윈도우 어디서나 열린다. VP9 WebM은 아이폰·일부 프로그램에서 안 열려 대안으로만
- 비트레이트를 직접 정한다(화소·장면당 비트, 원본의 90% 넘지 않음): 브라우저 인코더의 '화질' 값은 브라우저·하드웨어마다 결과가 달라 예상 용량을 보일 수 없다
- 목표 용량: 바이트 × 8 × 0.97 ÷ 길이 - 소리 비트레이트. 1MB = 1,000,000바이트 (이미지 용량 맞추기와 같게). 볼 만한 최소(`minimumBitrate`)보다 낮으면 경고, 소리만으로 넘치면 막는다
- 견본은 1080p 2Mbps로 만들었다: 720p로 줄이면 절반쯤이 되어 하는 일이 보인다 (처음 720p 견본은 더 줄지 않았다)

### 주의할 점

- 비트레이트는 `new Quality({ bitrate })`로 넘긴다 (`new Quality(숫자)`는 화질 단계). 실수하면 몇 배 커진다
- 예상 용량과 처리 규칙이 어긋나지 않게 `plan.ts`만 고친다

## 4. 검증

### 자동 테스트

- `tests/e2e/video-compress.spec.ts`
  - 480p·낮음: 해상도 후보 2개(원래·480p), 예상 용량, 저장 형식·소리 안내 → `clip_줄임.mp4`가 원본의 70% 미만, H.264 854×480, AAC 48kHz 2채널 그대로, 6초, 장면 색
  - 목표 용량: 소리보다 작으면 막음, 0.15MB → 1.4배 안, Opus 소리는 AAC(못 하면 Opus)
  - WebCodecs가 없으면 안내·버튼 막힘, 원본보다 커지면 받기 없음(영어 화면) → 설정을 바꾸면 다시 할 수 있음

# PDF 합치기 (`pdf/merge`)

- 주소: `/pdf/merge/` (영어 `/en/pdf/merge/`)
- 상태: live (2026-10-11 `b85a8c4`에서 공개로 바꿈)
- 관련 문서: [히스토리](./history.md), [PDF 공통](../../foundations/pdf-common/README.md),
  [격리 frame](../../foundations/frame-isolation/README.md), 가이드 `src/content/guides/{ko,en}/merge-pdf.md`
- 4단계에서 만들며 PDF 수정 도구의 공통 기반(조립 워커 `assemblePdf`, 썸네일, `ActionBar`, 다운로드 도우미, `canUse()`)이 같이 생겼다

## 1. 어떤 기능인지

- 여러 PDF를 원하는 순서로 하나로 합친다. 파일 안의 페이지 순서를 바꾸거나 일부 페이지를 뺄 수도 있다
- 입력: PDF 2개 이상 (개수 제한 없음). 암호 PDF는 목록에서 그 파일의 암호를 넣는다
- 출력: PDF 하나, 이름은 `<첫 파일 이름>_합침.pdf` (영어 `_merged.pdf`)
- 할 수 있는 것
  - 목록에서 줄 끌기 또는 ↑ ↓ 로 파일 순서 바꾸기, × 로 빼기, "파일 추가"
  - 파일 왼쪽 ▸ 로 페이지를 펼쳐 끌기·◀ ▶ 로 순서 바꾸기, "제외"·"복구"
  - "미리보기": 실제로 합치지 않고 합칠 순서대로 페이지를 이어 보여 준다
- 한계 (FAQ와 같음)
  - 모두 기기 메모리에서 처리해 메모리가 적은 휴대폰에서 수백 MB 파일은 느리거나 실패할 수 있다
  - 합친 파일에는 암호가 걸리지 않는다
  - 열 수 없는(손상된) 파일은 "빼고 합칩니다"로 표시하고 결과에서 뺀다

### 처리 흐름

1. 파일을 고르거나 놓으면 PDF만 골라 줄을 만들고, 줄마다 `openPdf()`로 쪽수와 첫 페이지를 읽는다 (`loading` → `ready` / `password` / `error`)
2. 암호 줄은 입력 칸 + "열기"(Enter). 맞는 암호는 줄에 기억해 두었다가 합칠 때 같은 암호로 푼다
3. 줄마다 `pages: GridPage[]`(원래 순번 + 제외 여부)를 두고, 펼친 격자가 이것을 고친다
4. 막을 이유(`blocker`): 읽는 중 / 암호를 안 넣은 줄 / 넣을 페이지가 있는 파일이 2개 미만
5. "PDF 합치기" → `canUse('pdf/merge')` → `assemblePdf({ sources, pages })` (원본 바이트 + 암호, `{source, index}` 순서 목록)
6. 끝나면 "다운로드" 버튼으로 바뀐다. 결과는 만든 때의 목록 상태(`signature`: 파일 순서 + 파일마다 넣을 페이지)와 묶여 있어, 목록을 바꾸면 결과를 버리고 다시 합치게 한다

조립 워커는 같은 원본의 페이지를 한 번에 `copyPages` 해서 글꼴·이미지 같은 공유 자원이 한 번만 들어가게 한다.

### 결정과 이유

- **페이지를 다시 그리지 않는다**: pdf-lib로 원본 내용을 그대로 옮겨 화질이 그대로다 (FAQ)
- **pdf-lib 대신 `@cantoo/pdf-lib`**: 원본은 2022년 이후 릴리스가 없고, 포크는 같은 API에 암호 PDF 열기를 지원한다 (`CLAUDE.md` "정한 것")
- **다운로드는 버튼 클릭으로만**: sandbox frame에서 사용자 클릭이 있어야 확실히 받아진다 (`97b9832`)
- **실행 막대를 목록 위에 둔다**: 모바일 하단 고정 광고와 멀어지게. 높이는 처리 전·중·후가 같다
- **미리보기는 실제 합치지 않고 원본에서 그린다**: 바로 열리고, 순서를 한눈에 보도록 쪽을 작게(최대 240px 폭) 그린다. Esc·닫기로 닫으면 포커스가 미리보기 버튼으로 돌아온다 (`bcc9804`). 도구 칸(격리 frame) 안의 화면이라 광고와 겹치지 않는다
- **끌기는 줄 머리에만**: 펼친 격자 안의 페이지 끌기와 섞이지 않게 줄을 줄 머리와 펼침 영역으로 나눴다 (`c4d2782`). 격자의 끌기 신호는 바깥 목록으로 퍼지지 않게 막는다
- **움직임**: 순서를 바꾸면 줄이 실제로 움직이고(`flip`) 옮긴 줄을 잠깐 강조한다. "움직임 줄이기" 설정이면 모션 없이 강조만 (`2b03351`)

### 주의할 점

- pdf.js는 받은 버퍼를 비워 버린다. 미리보기·썸네일용으로 열 때 `item.bytes.slice()`를 주고, 원본은 합칠 때 쓴다
- 파일 끌기('Files')는 frame 전체(`drop.ts`)가 받는다. 줄 끌기 처리는 `dragId`가 있을 때만 움직이고 파일 끌기는 건드리지 않는다
- 끌기를 시작할 때 `setData('text/plain', '')`가 필요하다 (일부 브라우저는 데이터가 없으면 끌기를 시작하지 않는다. 내용은 쓰지 않음)
- 암호를 넣기 전인 줄은 끌리지 않고 ↑ ↓ 도 숨긴다. 입력 칸의 글자 선택과 부딪히지 않고, 좁은 화면에서 암호 칸에 자리를 주려고 (`ef6067b`, `59aa1be`)
- ↑ ↓ 로 맨 위·맨 아래에 닿으면 누른 버튼이 꺼진다. 포커스를 반대 방향 버튼에 맞춘다 (`a34f31a`)
- `<form>`을 쓰지 않는다 (암호 입력은 Enter 키와 버튼으로)

### 자동 테스트

`tests/e2e/pdf-merge.spec.ts`

- 정한 순서대로 합치고, 암호 PDF도 풀어서 넣는다 (받은 파일의 쪽 글자 순서, `/Encrypt` 없음, 파일 이름 `encrypted_합침.pdf`)

- 줄을 끌어서 순서를 바꾼다
- 펼친 페이지에서 순서를 바꾸고 뺀 대로 합친다
- 펼친 페이지를 끌어서 순서를 바꾼다

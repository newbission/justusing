# pdf-merge — 검증·오류·수정 히스토리

쓴 날 2026-10-16 · 고친 날 2026-10-16

## 요약

- 2026-10-10: 준비 중으로 등록. 2026-10-11에 4단계로 만들면서 PDF 수정 도구의 공통 기반(조립 워커 `assemblePdf`, 썸네일, 다운로드 도우미, 실행 전 `canUse()`)이 같이 생겼다
- 2026-10-11: pdf-lib는 관리되는 포크 `@cantoo/pdf-lib`를 쓴다. 암호 PDF를 열 수 있어 암호 줄도 합칠 수 있다 (결과에는 암호 없음)
- 2026-10-11: 다운로드는 sandbox frame에서 사용자 클릭이 있어야 확실히 되므로 "다운로드" 버튼으로 받는다. 실행 막대는 높이를 고정하고 모바일 하단 광고와 멀도록 목록 위에 둔다 (`97b9832`)
- 2026-10-11: 합친 뒤 목록·페이지 설정이 바뀌면 결과를 버리고 다시 합치게 했다. 이 "결과와 상태 묶기(signature)"는 이후 모든 도구가 따른다
- 2026-10-11: 줄 끌기를 넣으며 파일 끌기('Files')는 frame 전체가, 줄 끌기만 목록이 처리하도록 나눴다. 암호를 넣기 전인 줄은 끌기·순서 버튼을 막아 입력 칸과 부딪히지 않게 했다
- 2026-10-11: 버튼으로 순서를 바꾸면 무엇이 바뀌었는지 몰라 움직임과 강조를 더했다. 맨 끝에 닿으면 키보드 포커스가 사라지던 문제를 반대 방향 버튼에 맞춰 고쳤다 (`a34f31a`)
- 2026-10-11: 줄을 펼쳐 파일 안의 페이지 순서·제외를 정하고, 합치기 전 미리보기를 더했다. 격자(`PageGrid`)는 정리 도구와 같이 쓴다
- 2026-10-11: 좁은 화면에서 암호 칸·막대 안내·쪽수 표시·펼친 격자가 깨지는 문제를 여러 번 고쳤다. 화면을 바꾸면 휴대폰 폭에서 확인한다

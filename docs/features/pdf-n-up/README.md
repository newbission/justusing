- 주소: `/pdf/n-up/` (영어 `/en/pdf/n-up/`)
- 상태: live. PR #52(2026-10-16 병합)의 내용이 main 배포 커밋 `89ddb74`("PDF 편집·모아찍기 배포")에 들어갔다
- 관련 문서: [히스토리](./history.md), [PDF 공통](../../foundations/pdf-common/README.md),
  가이드 `src/content/guides/{ko,en}/n-up-pdf.md`
- 7단계 가벼운 PDF 도구 (`CLAUDE.md`)

## 1. 어떤 기능인지

- PDF 여러 쪽을 종이 한 장에 2·4·6·9쪽씩 모아 새 PDF를 만든다. 강의 자료를 아껴 인쇄할 때 쓴다
- 입력: PDF 하나 (암호 PDF는 열 때 암호 입력)
- 출력: PDF 하나, `<이름>_모아찍기.pdf` (영어 `_n-up.pdf`)
- 고르는 것: 한 장에 넣을 쪽 수(2·4·6·9, 처음 4), 종이(A4·Letter, 한국어 화면은 A4, 영어 화면은 Letter부터), "쪽마다 테두리 선"
- 첫 장 미리보기: 쪽이 놓이는 모양을 쪽 그림으로 보여 준다 (왼쪽 위부터 가로로 채움)

| 쪽 수 | 칸 (가로×세로) | 종이 방향   |
| ----- | -------------- | ----------- |
| 2     | 2×1            | 가로로 눕힘 |
| 4     | 2×2            | 세로        |
| 6     | 3×2            | 가로로 눕힘 |
| 9     | 3×3            | 세로        |

- 할 수 있는 것 (FAQ와 같음)
  - 쪽을 그림으로 바꾸지 않고 원래 내용 그대로 줄여 넣는다. 확대해도 선명하고 글자 고르기·검색이 된다
  - 크기·방향이 다른 쪽도 비율을 지켜 칸 가운데에 둔다. 회전된 쪽은 화면에 보이는 방향 그대로
  - 인쇄되는 양식 입력값·서명·도장은 쪽에 그려 넣고, 화면 전용 버튼·메모 창은 뺀다
  - 형광펜·밑줄·취소선(물결 밑줄 포함)은 모양이 저장되어 있지 않아도 다시 그려 넣는다
- 한계 (FAQ·화면 안내와 같음)
  - 모양이 저장되어 있지 않은 그 밖의 주석, 기본 글꼴(Helvetica)에 없는 글자(한글 등)가 든 모양 없는 입력값이 있으면 결과를 만들지 않고 알린다:
    "PDF 보기 프로그램에서 '인쇄 → PDF로 저장'으로 한 번 저장한 뒤 다시 해 보세요"
  - 9쪽처럼 많이 모으면 인쇄했을 때 글자가 작아진다
  - 쪽 순서 바꾸기는 없다. 먼저 "PDF 페이지 정리"를 쓰라고 안내한다
  - 내용이 없는 빈 쪽은 pdf-lib가 넣지 못해 칸만 비운다 (테두리는 그린다)

## 2. 어떻게 만드는지

### 파일

| 파일                                 | 역할                                                                                            |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- |
| `src/tools/pdf/n-up/meta.ts`         | 이름·설명·아이콘, 묶음 `pages`, 관련 도구(정리·합치기)                                          |
| `src/tools/pdf/n-up/content.ts`      | 사용법 4단계·FAQ 6개                                                                            |
| `src/tools/pdf/n-up/messages.ts`     | 고르기 이름, 막대 안내, 주석을 옮길 수 없을 때 안내(`annotationFailed`)                         |
| `src/tools/pdf/n-up/App.svelte`      | 고르기, 첫 장 미리보기(`Thumbnail`을 칸에 맞춤), 실행 막대                                      |
| `src/lib/pdf/modify.ts`              | `modifyPdf(source, { kind: 'n-up', perSheet, paper, border })`, 타입 `NUpCount`·`PaperSize`     |
| `src/lib/pdf/modify.worker.ts`       | `nUp()`: 새 PDF를 만들어 칸마다 `embedPages`로 줄여 넣는다                                      |
| `src/lib/pdf/flatten-annotations.ts` | `renderMissingFormAppearances()`, `flattenAnnotations(page)`: 주석 모양을 쪽 내용에 그려 넣는다 |
| `src/lib/pdf/modify-errors.ts`       | `UNRENDERED_ANNOTATION`: 워커가 던지고 화면이 알아보는 오류 이름                                |
| `src/lib/pdf/page-geometry.ts`       | `viewSize()`, `normalizedRotation()` (보이는 크기·회전)                                         |
| `src/lib/pdf/page-content.ts`        | `isolateContent()`: 원래 쪽 내용을 감싸 그래픽 상태가 새지 않게 (글자층 겹치기와 같이 씀)       |

### 처리 흐름 (워커 `nUp()`)

1. 종이 크기(pt): A4 595.28×841.89, Letter 612×792. 눕히면 가로·세로를 바꾼다. 가장자리 18pt, 칸 사이 8pt
2. `renderMissingFormAppearances(doc)`: 모양(/AP) 없는 입력 칸에 pdf-lib로 모양을 만든다
   - 인쇄되는 위젯이 하나라도 있는 칸만 따진다
   - 값(드롭다운은 표시 문자열, 목록 상자는 선택지 전체)에 Helvetica에 없는 글자가 있거나, 드롭다운의 표시 문자열이 내보내는 값과 다르면 `UNRENDERED_ANNOTATION`
3. 쪽마다 `flattenAnnotations(page)`
   - 메모 창(Popup)과 인쇄되지 않는(`Print` 플래그 없음 또는 `Hidden`) 주석은 건너뛴다
   - 지금 보이는 모양(/AP /N, 상태가 여럿이면 /AS) 또는 형광펜·밑줄·취소선·물결 밑줄은 /QuadPoints·/C·/CA로 만든 모양
   - 모양의 BBox를 /Matrix로 옮긴 영역을 Rect에 맞춰 원래 쪽 내용 위에 덧그린다 (ISO 32000 12.5.5). 처음 그릴 때 `isolateContent()`로 원래 내용을 감싼다
   - 그릴 수 없으면 `UNRENDERED_ANNOTATION`. 끝나면 쪽의 /Annots를 지운다
4. 내용(`Contents`)이 있는 쪽만 CropBox 기준으로 `embedPages`
5. 쪽 순서대로 칸을 채운다. 보이는 크기(`viewSize`)를 칸에 비율대로 맞춰 가운데에 두고, 회전한 쪽은 `rotate: -rotation`과 돌린 뒤의 왼쪽 아래 기준점으로 그린다. 테두리는 회색 0.5pt
6. 화면: 오류 메시지가 `UNRENDERED_ANNOTATION`이면 `annotationFailed`, 아니면 일반 실패 안내

### 결정과 이유

- **`embedPages`로 줄여 넣는다**: 그림으로 바꾸면 흐려지고 글자 검색이 안 된다 (`e557775`)
- **주석을 먼저 평면화한다**: `embedPages`는 쪽 내용만 옮겨 작성한 신청서의 입력값·서명·도장이 결과에서 조용히 빠졌다 (`c4c23d2`, 리뷰 P1)
- **인쇄 기준으로 고른다**: 종이에 찍을 결과라 인쇄되는 주석만 넣는다. 화면 전용은 빼고 인쇄 전용은 넣는다 (`e3a5d35`)
- **조용히 빼지 않고 알린다**: 그릴 수 없는 주석·입력값이 있으면 결과를 아예 만들지 않는다. 내용이 빠진 결과를 모른 채 쓰는 것보다 낫다고 정했다 (`9d5effb`, `8c859b6`)
- **미리보기 종이 비율 = 워커 종이 비율**: `PAPER_RATIO`와 `GRID`를 워커와 같은 값으로 둔다. Letter를 골라도 A4 비율이던 것을 고쳤다 (`398d58b`)
- **영어 화면은 Letter부터**: 미국 기본 종이

### 주의할 점

- `GRID`·종이 크기는 `App.svelte`와 `modify.worker.ts` 두 곳에 있다. 하나를 바꾸면 다른 곳도 맞춘다
- pdf-lib는 기본 글꼴에 없는 글자를 **오류 없이 빼 버린다**. 모양을 만들기 전에 글자 지원을 먼저 검사하는 순서를 지킨다
- 드롭다운: pdf-lib는 내보내는 값을 그린다. 표시 문자열이 다르면 같은 모양을 만들 수 없다 (`8ca4bb9`)
- QuadPoints는 Acrobat 순서(왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래)로 읽는다. 기울어진 글자의 형광펜은 사변형으로 칠하고 밑줄은 아래 변 방향을 따른다 (`406154a`)
- `flattenAnnotations`는 원본 문서를 고친다. 워커 안에서 새로 연 문서에만 쓴다
- 링크 주석: dev의 코드는 인쇄 플래그가 있고 모양(/AP)이 없는 링크(목차 링크 등)를 "그릴 수 없는 주석"으로 보고 결과를 막는다. 고친 커밋(`cabf22f` 링크 건너뛰기, `9f3a926`·`00c1423`·`af21626` 링크 테두리 그리기)은 아직 `feat/pdf-redact` 브랜치에만 있다

## 4. 검증

### 자동 테스트

`tests/e2e/pdf-n-up.spec.ts` (받은 PDF의 쪽 크기와, 쪽 내용에서 그려 넣은 쪽·테두리·선의 자리를 읽어 확인)

- 2쪽 모아찍기는 A4를 눕혀 두 쪽씩 놓는다 (842×595, 왼쪽 칸 1쪽·오른쪽 칸 2쪽, 이름 `three-pages_모아찍기.pdf`)
- 회전된 쪽은 보이는 방향 그대로 넣고, 테두리를 그린다 (Letter 미리보기 비율, 빈 쪽은 칸과 테두리만)
- 양식 입력값·주석처럼 주석으로 보이는 내용도 함께 옮긴다 (인쇄 플래그 기준 포함)
- 모양 없이 저장된 양식 입력값은 모양을 만들어 옮긴다
- 모양을 만들 수 없는 양식 입력값이 있으면 조용히 빼지 않고 알린다
- 인쇄되지 않는 입력 칸은 한글 값이 있어도 막지 않는다
- 모양 없이 저장된 형광펜은 다시 그려 넣고, 그릴 수 없는 주석은 알린다 (물결 밑줄·기울어진 밑줄 포함)
- 드롭다운의 표시 글자를 그릴 수 없으면 알린다
- 모으는 동안의 요청에는 파일이 기기 밖으로 나가는 것이 없다 (`expectLocalOnly`)

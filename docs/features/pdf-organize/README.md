## 1. 어떤 기능인지

- PDF 한 파일의 쪽 순서를 바꾸고 필요 없는 쪽을 빼서 새 PDF로 받는다
- 입력: PDF 하나 (암호 PDF는 열 때 암호 입력)
- 출력: PDF 하나, `<이름>_정리.pdf` (영어 `_organized.pdf`)
- 할 수 있는 것
  - 썸네일을 끌거나 ◀ ▶ 로 순서 바꾸기. 쪽 왼쪽 위 번호가 결과에서의 순서
  - "제외"(흐리게 표시) · "복구", "되돌리기"로 처음 상태
  - 위쪽 요약: `3쪽 중 2쪽 남김 · 순서 바뀜`
- 한계 (FAQ와 같음)
  - 여러 PDF의 쪽을 섞으려면 합치기 도구를 쓴다 (FAQ가 안내)
  - 결과 파일에는 암호가 걸리지 않는다. 원본 파일은 바뀌지 않는다

## 2. 어떻게 만드는지

### 파일

| 파일                                 | 역할                                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------------------ |
| `src/tools/pdf/organize/meta.ts`     | 이름·설명·아이콘, 묶음 `pages`, 관련 도구(회전·합치기)                               |
| `src/tools/pdf/organize/content.ts`  | 사용법 4단계·FAQ 4개                                                                 |
| `src/tools/pdf/organize/messages.ts` | 막대 안내("남길 쪽이 하나도 없습니다", "바꾼 내용이 없습니다"), 요약                 |
| `src/tools/pdf/organize/App.svelte`  | 요약·되돌리기, 실행 막대, `PageGrid`                                                 |
| `src/lib/pdf/PageGrid.svelte`        | 번호 붙은 썸네일 격자: 끌기·◀ ▶ 로 순서, 제외·복구. 합치기의 펼친 페이지와 같이 쓴다 |
| `src/lib/pdf/SinglePdfTool.svelte`   | 파일 고르기·암호·파일 이름 막대                                                      |
| `src/lib/pdf/assemble.ts`            | `assemblePdf()`로 남긴 쪽만 정한 순서로 모은다                                       |

### 처리 흐름

1. 파일이 열리면 `pages`를 `{ index, excluded: false }`로 원래 순서대로 채운다
2. `PageGrid`가 `pages` 배열을 그대로 고친다 (배열 순서 = 결과 순서, `excluded` = 결과에서 뺌)
3. 막을 이유: 남긴 쪽이 0 / 순서도 그대로이고 뺀 쪽도 없음
4. "PDF 정리" → `canUse('pdf/organize')` → `assemblePdf`에 남긴 쪽의 `{ source: 0, index }`를 순서대로
5. 결과는 남긴 쪽 순서(`signature`)와 묶여 있어, 바꾸면 결과를 버린다

### 결정과 이유

- **쪽을 다시 그리지 않는다**: 원본 내용을 그대로 옮겨 화질이 그대로 (FAQ)
- **한 파일만 다룬다**: 도구마다 한 가지 일만 한다. 여러 파일 섞기는 합치기의 "펼친 페이지"가 맡는다 (`CLAUDE.md` "정한 것": 정리에 여러 파일 넣기는 필요할 때 더한다)
- **격자는 합치기와 같은 부품**: 결과에 들어가는 쪽만 1부터 번호를 매기고, 원래 몇 쪽이었는지는 썸네일 이름으로 알린다

### 주의할 점

- `PageGrid`를 고치면 합치기 화면(줄 안의 펼친 격자)도 같이 바뀐다. 격자 끌기 신호가 바깥 목록으로 퍼지지 않게 막는 처리를 지킨다
- 파일 끌기는 frame 전체(`drop.ts`)가 받는다. 격자 끌기는 격자 안에서 시작한 끌기만 처리한다

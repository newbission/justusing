## 1. 어떤 기능인지

- PDF 쪽에서 남길 영역을 골라 여백이나 필요 없는 가장자리를 잘라 낸다
- 입력: PDF 하나 (암호 PDF는 열 때 암호 입력)
- 출력: PDF 하나, `<이름>_자름.pdf` (영어 `_cropped.pdf`)
- 할 수 있는 것
  - 쪽 위의 밝은 사각형 = 남길 영역. 모서리 동그라미를 끌어 크기, 가운데를 끌어 자리. 바깥은 어둡게 덮는다
  - 키보드: 영역·모서리마다 버튼이 있고 화살표로 1%, Shift+화살표로 5%씩 옮긴다
  - ‹ › 로 쪽 바꾸기, "이 쪽만" / "모든 쪽", "처음대로"(가장자리 5%씩 안쪽)
  - "모든 쪽"은 쪽마다 화면에 보이는 모습 기준 같은 비율의 영역을 남긴다 (돌린 쪽도 화면 기준)
- **한계 (화면 안내·FAQ와 같음)**
  - 잘라 낸 부분은 **보이지 않을 뿐 파일 안에 남아 있다.** 다른 프로그램으로 다시 보이게 할 수 있어 개인정보를 지우는 용도로 쓰지 말라고 화면(`messages.ts`의 `note`)과 FAQ에 밝힌다
  - 쪽마다 다른 영역은 한 번에 못 한다. "이 쪽만"으로 자르고 받은 PDF를 다시 열어 다른 쪽을 자른다 (FAQ)
  - 영역의 최소 크기는 쪽의 5%

## 2. 어떻게 만드는지

### 파일

| 파일                                         | 역할                                                                    |
| -------------------------------------------- | ----------------------------------------------------------------------- |
| `src/tools/pdf/crop/meta.ts`                 | 이름·설명·아이콘, 묶음 `pages`, 관련 도구(회전·정리)                    |
| `src/tools/pdf/crop/content.ts`              | 사용법 4단계·FAQ 3개                                                    |
| `src/tools/pdf/crop/messages.ts`             | 막대 안내, 범위 이름, "처음대로", 남아 있다는 안내(`note`)              |
| `src/tools/pdf/crop/App.svelte`              | 범위 고르기, 처음대로, 실행 막대, `CropEditor`                          |
| `src/lib/pdf/CropEditor.svelte`              | 남길 영역 고르기 화면 (끌기·키보드, 최소 크기 `MIN = 0.05`)             |
| `src/lib/pdf/PageSheet.svelte`               | 쪽을 크게 그리고 위에 겹쳐 조작하는 공통 틀 (‹ › 쪽 넘기기 포함)        |
| `src/lib/pdf/modify.ts` + `modify.worker.ts` | `modifyPdf(source, { kind: 'crop', rect, pages })`                      |
| `src/lib/pdf/page-geometry.ts`               | `scaleRect()`, `toPdfPoint()`: 화면 비율 → PDF 좌표 (회전·CropBox 반영) |
| `src/frame/messages.ts`의 `crop`             | 영역·모서리 버튼의 스크린리더 이름, 도움말                              |

### 처리 흐름

1. 파일이 열리면 쪽 0, 영역 `{ x: 0.05, y: 0.05, width: 0.9, height: 0.9 }`, 범위 "이 쪽만"
2. `CropEditor`가 `rect`(화면에 보이는 쪽 기준 비율, 왼쪽 위 0,0)를 고친다. 쪽을 바꿔도 같은 영역이 이어진다
3. 범위에 따라 `pages` = 지금 쪽 하나 또는 모든 쪽
4. "PDF 자르기" → `canUse('pdf/crop')` → 워커
5. 워커: 쪽마다 `scaleRect()`로 보이는 크기(pt)로 바꾸고, 두 모서리를 `toPdfPoint()`로 PDF 좌표로 옮긴 뒤 `setCropBox`·`setTrimBox`
6. 결과는 만든 때의 `signature`(쪽 목록 + 영역 소수 넷째 자리)와 묶여 있어, 영역이나 범위를 바꾸면 결과를 버린다

### 결정과 이유

- **보이는 영역(CropBox)만 줄인다**: 쪽을 다시 그리지 않아 화질이 그대로다. 대신 잘린 내용이 파일에 남으므로 이 사실을 화면·FAQ에 밝히기로 했다 (`CLAUDE.md` 7단계). 진짜 지우기는 별도 도구(가리기, `pdf-redact`)가 맡는다
- **TrimBox도 같은 영역으로 맞춘다** (워커 `crop` 처리. 커밋에 따로 적힌 이유는 없다)
- **자리는 화면 기준 비율로 넘긴다**: 쪽의 회전·기존 CropBox 계산은 워커가 한다. 화면과 결과가 같은 자리가 되고, 크기가 다른 쪽에도 같은 비율로 적용된다 (`src/lib/pdf/modify.ts` 머리 주석)

### 주의할 점

- 영역은 **지금 보이는 쪽**(이미 있는 CropBox와 회전 적용) 기준이다. `page-geometry.ts`를 고치면 이미지 넣기·서명·글자 넣기 도구도 같이 바뀐다
- `controls.css`의 공통 모양(`tool-body`, `choices`, `btn`)을 쓴다. HTML `style` 속성은 쓰지 않는다 (CSP)
- 한계 문구를 바꿀 때 화면 `note`와 FAQ를 함께 고친다

# pdf-edit — 검증·오류·수정 히스토리

## 요약

- 2026-10-10: '준비 중'으로 등록하고 MVP에서 뺐다. 2026-10-15에 글꼴 기반 위에 글자·흰색 가리기·형광펜으로 만들었다
- 글자 넣기 워커에 편집 작업을 더했다. 사각형을 먼저, 글자를 나중에 그려 가린 자리 위에 고쳐 쓸 수 있게 하고,
  글자가 없으면 글꼴 없이도 된다
- 흰색 가리기는 아래 내용이 남는다고 화면·FAQ·가이드에 밝혔다. 진짜 지우기는 따로 만든다 (pdf-redact)
- 리뷰 P1: 글자 도구로 가린 자리를 누르면 사각형이 눌림을 가로채 옮기기만 했다 → 글자 도구에서는 사각형이 눌림을 받지 않는다
- 리뷰 P1: 쪽 위를 누르거나 끌어야만 넣을 수 있어 키보드로는 하나도 못 넣었다 → "가운데에 넣기" 버튼, 화살표·Alt+화살표·Delete
- 미리보기는 넣은 순서대로 겹쳐 결과(글자가 늘 위)와 달랐다 → 저장은 그대로 두고 미리보기를 같은 순서로 맞췄다
- Tab으로 옮겨 가도 고른 상태가 안 되었고, 범위 밖 글자 크기가 칸에 남았다 → 포커스로 고르고, 칸을 떠날 때 되돌린다
- 한 쪽 문서에서 표지를 뺀 머리말처럼 넣을 글자가 없는 작업이 실패했다 → 글꼴 없이 그대로 저장 (워커 공통 수정)
- 배운 점: 미리보기와 저장의 겹침 순서는 두 곳(CSS, `drawEdits`)에 있어 함께 고쳐야 화면과 결과가 같다
- 2026-10-15: 배포 (PR #54는 2026-10-16 dev 병합)

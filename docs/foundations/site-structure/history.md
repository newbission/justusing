- 2026-10-14~15: 도구가 늘어 목록을 묶음별 소제목으로 나누고 아이콘을 붙임(PR #30). 이미지 카테고리 추가
- 2026-10-24: 성능 철칙(사용자: "사이트가 무거워지거나 느려지면 안 된다")을 자동으로 지키려고 성능 예산 E2E를 더했다. 재 보니 모든 PDF 도구가

  배운 점: 도구를 더할 때 첫 화면에서 받는 것을 한 번 재 본다 (`scripts/perf/measure.mjs`)

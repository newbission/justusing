## 요약

- 2026-10-13: 한국어·영어 두 언어로 정함. 한국어는 지금 주소 그대로, 영어는 `/en/` 아래. 페이지 언어는 주소에서 정해
  부품이 언어를 넘겨받지 않게 함. 영어 라우트는 한국어 페이지를 그리는 얇은 파일, 글 페이지만 영어 글을 따로 씀
- 2026-10-13: 격리 frame은 바깥 주소·저장값을 볼 수 없어 자기 문서의 `<html lang>`으로 언어를 고르게 함 (`frameLocale`, `pick`)
- 2026-10-13: 처음 방문 때 브라우저 언어로 보내기. 검색 로봇은 보내지 않는다 — 구글 로봇은 영어 브라우저라 보내면
  한국어 페이지가 한국어 검색에서 빠진다. 대신 `hreflang`으로 언어판을 알린다. E2E 브라우저도 보내지 않아 테스트에서만 켠다
- 2026-10-13: 영어 방침·약관에 "다르면 한국어판이 기준"을 적음. 두 언어를 함께 고치고 시행일을 맞추는 규칙을 둠
- 2026-10-14 (PR #17 리뷰 P1 두 개): 안전 그림에 사이트명을 직접 씀 → `siteConfig.name`으로, 안전 그림 E2E가 없음 → 한·영 E2E 추가
- 2026-10-14 (PR #20): 영어 문구 전체 검수. 리뷰에서 pdf.js CMap을 "글꼴 데이터"라고 쓴 것을 지적받아 "글자 매핑"으로 고침.
  배운 점: 화면·방침 문구는 실제 구현과 같은 말로 쓴다
- 2026-10-15: 가이드 글도 모든 언어판을 같은 주소 이름으로 쓰고, 빠지면 빌드를 멈추게 함

## 요약

- 2026-10-10: 광고 자리 6개와 크기를 정함. CSP가 `style=""`를 막아 슬롯 크기를 `slots.css` 한 곳으로 옮김.
  슬롯마다 업체를 고르게 해 특정 업체에 묶이지 않게 함. 모바일 하단 광고는 숨기지 않고 접기 탭만 둠
- 2026-10-11: 가로 배너 자리를 사용자 피드백에 따라 옮김 (홈·카테고리 제목 아래 → 머리글 바로 아래 → 다시 각 페이지 제목 아래).
  도구 페이지는 도구 칸 맨 위의 실행 버튼과 붙지 않게 32px 띄움
- 2026-10-11 → 10-13: 쿠키 동의를 "전 세계 공통 배너"로 정했다가, 거절하면 광고가 아예 없어져 버려 우리 배너를 만들지 않기로 다시 정함.
  광고는 모든 방문자에게, 유럽은 AdSense의 Google 동의 메시지가 맡는다
- 2026-10-13 (PR #8): 쿠키 없는 Cloudflare 통계. 리뷰에서 통계 요청의 본문만 보고 주소는 안 본다고 지적받아,
  `expectLocalOnly`가 디코딩한 주소(경로·쿼리)도 파일 이름·PDF 표식으로 검사하게 고침
- 2026-10-13 (PR #12): AdSense 소유 확인은 광고 스크립트가 아니라 메타 태그와 `ads.txt`로 (동의 없이 쿠키를 쓰지 않게)
- 2026-10-14 (PR #14 리뷰 P1): `ads.enabled`를 꺼도 스크립트와 안내 창이 돌아 "스위치 하나" 약속이 깨졌다 → 셋을 함께 끄고,
  심사 중에는 켜 둔 채 `slots`만 비움
- 2026-10-14 (PR #14 리뷰 P1): 광고 내용을 방침에 더하고 시행일을 안 바꿈 → 광고 적용일로 고침. 이후 "통계·광고·쿠키를 바꾸면
  같은 PR에서 방침과 시행일" 규칙을 지킴
- 2026-10-14 (PR #14 리뷰 P1, 미반영): AdSense는 주소 허용 목록 CSP를 지원하지 않는다. 정적 사이트라 nonce를 못 써 지금은
  허용 목록으로 두고, 광고 칸·유럽 동의 창을 켤 때 실제 콘솔로 확인하기로 함 (알려진 위험)
- 2026-10-13: 광고 차단 안내 창은 사용자가 "기다리게 하지 않는다" 규칙의 예외로 정함. 언제든 닫히고 하던 일을 막지 않으며,
  frame이 보내는 활동 신호에는 내용이 없다
